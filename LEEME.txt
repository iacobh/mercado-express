COMPRA Y VENTA V11 - MERCADO PAGO (MODO PRUEBA)

Esta versión agrega:
- Pago dentro del sitio con Mercado Pago Checkout API + Payment Brick.
- Comisión de Compra y Venta del 10% para productos de vendedores.
- Conexión de cada vendedor con Mercado Pago mediante OAuth.
- El Access Token privado nunca se envía al navegador.

VARIABLES DE RENDER
Ya configuradas:
- ADMIN_PASSWORD
- MP_ACCESS_TOKEN = Access Token de prueba de la cuenta integradora
- MP_PUBLIC_KEY = Public Key de prueba de la cuenta integradora

Faltan para el flujo marketplace con vendedores:
- MP_CLIENT_ID = Client ID / App ID de la aplicación Mercado Pago
- MP_CLIENT_SECRET = Client Secret de la aplicación (NO subir a GitHub)
- MP_REDIRECT_URI = https://mercado-express-5pcs.onrender.com/api/mp/oauth/callback

En Mercado Pago Developers, la Redirect URL de la aplicación debe ser EXACTAMENTE la misma que MP_REDIRECT_URI.

IMPORTANTE
- Esta versión es para PRUEBAS. No uses tarjetas reales.
- Para cobrar comisión a vendedores reales, cada vendedor debe conectar su cuenta de Mercado Pago desde "Mi cuenta".
- Por ahora un pago solo puede incluir productos de UN vendedor. Si el carrito mezcla vendedores, la web pide separarlo.
- Antes de pasar a producción conviene migrar SQLite a PostgreSQL, usar almacenamiento persistente para imágenes, cifrar tokens OAuth y configurar Webhooks de Mercado Pago.
