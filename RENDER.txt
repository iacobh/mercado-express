MERCADO EXPRESS V9 - RENDER

Build Command:
pip install -r requirements.txt

Start Command:
gunicorn app:app --workers 1 --threads 4 --bind 0.0.0.0:$PORT

Environment Variables to create in Render:
ADMIN_USERNAME = admin
ADMIN_PASSWORD = (ponerla manualmente en Render; NO subirla a GitHub)
SECRET_KEY = (generar un valor secreto en Render)

Optional later for persistent disk:
DATA_DIR = /var/data

IMPORTANT:
Do not upload admin_config.json.
The admin password is not stored in this repository.
